# 稳盈

稳盈是一款面向个人银行理财、基金与定期存款的本地优先桌面应用。它把分散在银行 App、Excel 和个人记录中的买入批次、当前市值、到期日期与实际回款统一到一个可追溯的账本中。

所有业务数据都保存在本机 SQLite 数据库中。应用不会上传账户或资产信息，导入 Excel 时也只读取源文件，不会修改原表。

## 适合解决的问题

- 同一产品多次买入后，还剩下多少成本，每个批次持有了多久？
- 部分赎回或到期时，如何按 FIFO 核销成本并保留完整流水？
- 不同银行、币种和产品的当前市值、未实现收益和已实现收益分别是多少？
- 银行 App 中的理财、存款和活期余额，与自己的账本是否一致？
- 历史收益、分红、费用、现金流和 XIRR 能否用一套明确口径复核？
- 误操作后能否安全恢复，而不是直接删除历史？

## 核心功能

### 资产总览

- 按人民币和美元分别汇总理财、定存、活期与总资产。
- 使用各银行最近一次对账汇率折算人民币总资产；缺少汇率时明确标记为暂估。
- 展示当前持仓数量、未实现收益、数据质量告警和近期到期项目。

### 当前持仓

- 按产品、购买渠道、币种和操作参考筛选。
- 展示剩余成本、当前市值、持有收益、近 30 日估值收益和数据新鲜度。
- 「持有期」同时展示当前剩余批次的最长、最短持有天数及批次数，并支持按最长持有期排序。
- 可一次批量更新全部持仓市值；每个产品都保留独立、可冲销的估值流水。
- 点击持仓可查看市值历史、近 7 日/30 日估值收益与风险等级。
- 根据估值变化、累计收益、风险等级和持仓占比生成可解释的复核提示。

### 交易与批次

- 支持买入、卖出、理财到期、分红、费用和同币种转账。
- 每次买入自动创建独立批次；多次买入、部分卖出时按 FIFO 核销剩余成本。
- 流水可按日期、操作、银行、币种和状态组合检索。
- 支持修改最新的可编辑流水，修改后自动重算 FIFO 成本、市值与收益。
- 「撤销」会新增反向冲销记录，保留原始流水并恢复相关批次、市值或定存状态。

### 定期存款与到期日历

- 结构化记录存款银行、本金、起息日、到期日、年利率和状态。
- 自动标记过期存款，并在日历中按月汇总未来到期项目。
- 到期取出时把本金和利息分开记录，避免把本金误认为收益。

### 历史理财与收益分析

- 汇总 Excel 历史赎回和应用内已全部卖出/到期的持仓。
- 展示首次买入日、结清日、持有天数、投入成本、实际回款、已实现收益、总收益率和简化年化收益率。
- 按币种计算 XIRR、累计已实现收益、近 12 个月资产趋势和月度现金流。
- 历史赎回可再次核对实际到账日期和金额，核对结果在重新导入 Excel 后继续保留。

### 银行对账与数据质量

- 按银行录入 App 中的理财、存款、活期三个人民币口径分项。
- 同一银行的人民币和美元资产按当次 USD/CNY 汇率合并对账。
- 对账中心集中显示未匹配差额、过期估值、缺少产品资料和待核对历史流水。
- 数据质量问题可直接跳转到相应处理页面。

### 资料管理与数据交换

- 编辑产品、账户和定期存款资料，修改前自动备份并保留审计记录。
- 同一产品可关联多个购买银行/账户。
- 导入现有 `理财.xlsx` 中的买入批次、当前持仓、定存和历史赎回。
- 导出包含资产概览、当前持仓、交易流水、定存、买入批次和市值历史的 Excel 数据包。

## 推荐使用流程

1. 首次启动后，导入现有的 `理财.xlsx`，或从「记一笔」开始手工建账。
2. 在「对账与数据质量」中补齐币种、风险等级、定存起息日等缺失信息。
3. 每周或获得新净值后，在「当前持仓」中批量更新市值。
4. 发生买入、卖出、分红、费用或到期时及时记录；批次和成本会自动维护。
5. 定期在对账中录入银行 App 分项与汇率，检查账本与银行余额是否一致。
6. 需要离机存档时，使用「数据安全」创建 SQLite 备份或导出 Excel 数据包。

## 关键计算口径

### 成本与收益

- 每次买入都形成独立批次。
- 部分卖出先用「到账金额 ÷ 卖出前总市值」计算卖出比例，再按 FIFO 从最早批次核销对应成本。
- 理财到期会结清该产品在指定渠道下的全部剩余批次。
- 已实现收益 = 实际到账金额 − 本次核销成本。
- 分红直接计入已实现收益；费用作为负收益，两者都不改变持仓成本或当前市值。
- 同币种账户转账只记录资金路径，不计入收益或总资产变化。

### 估值与持有期

- 市值由用户手工录入；更新市值不改变成本，旧值保留为历史快照。
- 阶段估值收益使用「更新后市值 ÷ 更新前市值」；买入和卖出造成的市值机械变化不计为产品涨跌。
- 当前持仓的最长持有期从最早的未结清批次起算，最短持有期从最近的未结清批次起算。
- 历史持仓的简化年化收益率使用首次买入日和结清日；多次买入或部分卖出时仅供参考。
- XIRR 仅使用日期和方向明确的投入、回款、分红和费用，并加入当前理财市值。缺少开户日期的历史导入定存不会强行参与计算。

### Excel 历史数据

- 重新导入时只替换上一次由 Excel 生成的记录，不会删除应用内的手工交易、成本核销结果或最新手工估值。
- Excel 买入流水的日期、金额和备注修正会单独保存，后续重新导入时自动沿用。
- 历史赎回优先使用表中的实际到账金额；同一产品、银行下的多个已结束批次先合并成本，再生成赎回流水。
- 缺少历史赎回金额时，才会按原成本生成待核对占位流水。

### 对账与操作参考

- 银行对账统一使用人民币口径：人民币资产直接计入，美元理财和存款使用当次快照中的 USD/CNY 汇率折算。
- 理财与存款分项差额均不超过 1 元时视为匹配；同一银行、同一天的新快照会覆盖当天旧快照。
- 「待更新、积累数据、继续观察、关注加仓、考虑止盈、评估赎回」是基于已记录数据的规则化复核提示，不是投资建议或收益保证。

## 数据安全

应用在每日首次启动、重新导入 Excel、修改流水、冲销交易和恢复数据库前自动创建备份。

- 主数据库：`wealth-manager.sqlite3`
- 自动备份：数据库同级 `backups` 目录
- 手工备份：可选择任意位置保存完整 `.sqlite3` 文件
- 恢复保护：恢复前先执行 SQLite 完整性检查，并自动保存当前数据库

macOS 上的具体应用数据路径由 Tauri 按应用标识 `com.wangziyang.wealthmanager` 管理。

## 技术栈与项目结构

- 桌面容器：Tauri 2
- 前端：React 19 + TypeScript + Vite
- 后端：Rust
- 数据库：SQLite（`rusqlite`）
- Excel 读取：`calamine`
- Excel 导出：`rust_xlsxwriter`

```text
wealth-manager/
├── src/                  # React 界面、交互与样式
├── src-tauri/
│   ├── src/lib.rs          # 数据库、导入导出、核算与 Tauri 命令
│   ├── tauri.conf.json     # 窗口、打包与应用元数据
│   └── icons/              # 应用图标
├── package.json
└── README.md
```

## 本地开发

### 环境要求

- Node.js 与 pnpm
- Rust stable toolchain
- Tauri 2 对应的系统构建依赖
- macOS 打包需要 Xcode Command Line Tools

### 安装与启动

```bash
pnpm install
pnpm tauri dev
```

### 检查与测试

```bash
# TypeScript 类型检查
pnpm check

# 前端生产构建
pnpm build

# Rust 格式检查
cargo fmt --manifest-path src-tauri/Cargo.toml -- --check

# Rust 单元和导入导出测试
cargo test --manifest-path src-tauri/Cargo.toml
```

部分导入测试会读取仓库上级的参考 `理财.xlsx`；如果文件内容与测试基准不同，固定数量断言会失败。

### 构建桌面应用

```bash
# Release 应用与安装包
pnpm tauri build

# 仅构建可执行文件，用于快速调试
pnpm tauri build --debug --no-bundle
```

macOS Release 产物默认位于：

```text
src-tauri/target/release/bundle/macos/
src-tauri/target/release/bundle/dmg/
```

当前安装包为本地未签名构建，还未接入 Apple 公证和自动更新。

## 主要数据表

| 数据表 | 用途 |
| --- | --- |
| `accounts` | 购买渠道和银行账户 |
| `products` | 理财/基金产品主数据 |
| `product_purchase_channels` | 产品与购买账户的多对多关系 |
| `transactions` | 买入、赎回、估值、分红、费用和冲销流水 |
| `position_lots` | 分批买入、剩余成本和批次状态 |
| `valuations` | 产品市值历史 |
| `deposits` | 定期存款合同与到期状态 |
| `import_runs` | Excel 导入历史与校验警告 |
| `master_data_changes` | 产品、账户和存款资料修改审计 |
| `institution_reconciliation_snapshots` | 银行分项余额、汇率和对账快照 |
| `historical_redemption_confirmations` | 历史赎回的人工核对结果 |
| `excel_transaction_corrections` | Excel 买入流水的持久化修正 |
| `account_balance_snapshots` | 旧版账户总余额快照，仅为备份兼容保留 |

## 已知边界

- 市值和净值不会自动从银行或基金平台拉取，需要用户录入。
- 应用的主要开发和真实工作簿验证环境是 macOS。
- 当前发布产物未签名、未公证，也未接入自动更新。
- 操作参考仅用于帮助复核数据，不替代对产品期限、赎回费、流动性和个人风险承受能力的判断。
